    💡 Still using Integrated GPU (iGPU)?

    By default, Windows and macOS force web browsers onto power-saving integrated graphics to save battery. To unlock your dedicated NVIDIA or AMD graphics card for browser tests:

    🪟 Windows 11 / 10 (NVIDIA / AMD)
    1. Open Windows Settings > System > Display > Graphics.
    2. Find your browser (Chrome / Edge / Firefox) in the list (or click Browse to add it).
    3. Click Options and select "High performance (NVIDIA / AMD GPU)".
    4. Restart your browser and re-run this test!
    🍎 macOS (MacBook Pro / Dual GPU)
    1. Open System Settings > Battery.
    2. Click Options at the bottom.
    3. Turn OFF "Automatic graphics switching" (forces high-performance dGPU).
    🌐 Chrome / Edge Flag
    1. Type chrome://flags in your address bar.
    2. Search for "Force dedicated GPU" or "Default ANGLE graphics backend".
    3. Set to D3D11 or OpenGL and relaunch.
